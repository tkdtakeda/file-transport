# PDF自動仕分けツール

同じフォルダに置いたPDFを、ファイル名のキーワードと年月から判断して、指定フォルダへ自動で振り分けます。
Windows のローカル環境だけで動作し、外部ネットワークへは一切送信しません。

- 仕様: [ファイル移動仕様書.md](ファイル移動仕様書.md)
- 画面の設計ルール: [基本設計.md](基本設計.md)

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `pdf_sorter_app.py` | 本体（Python標準ライブラリのみ。画面のHTML/CSS/JSも内蔵） |
| `rules.json` | 共通設定と仕分けルール。画面から編集・保存する |
| `edit_rules.bat` | ルール編集画面を開く |
| `run_sort.bat` | PDF移動を実行する |
| `run_preview.bat` | 移動予定先だけを表示する（移動しない） |
| `_log/move_log.csv` | 実行結果のログ（UTF-8 BOM付き。Excelでそのまま開ける） |
| `_unknown/` | ルールに一致しなかったPDFの退避先 |
| `_rules_backup/` | `rules.json` を保存するたびに作られるバックアップ（最新20件） |

## 使い方

1. このフォルダ一式を、仕分けしたいPDFを置くフォルダにコピーします。
2. `edit_rules.bat` を実行し、ブラウザで **共通保存先フォルダ** と **仕分けルール** を設定して保存します。
3. PDFをこのフォルダに置き、`run_sort.bat` を実行します（画面の「PDFを移動する」からでも実行できます）。

前提として Python 3.x が必要です。`py` コマンドが無い環境では `python` が使われます。

## 画面

`edit_rules.bat` を実行すると `http://127.0.0.1:8765/` でルール編集画面が開きます。

- **左: 仕分けルール** — 有効／無効、優先順位、キーワード、保存先サブフォルダを編集します。カードの下に、そのルールの保存先が実際のパスで表示されます。
- **右: 判定結果** — 実行前は対象PDFの一覧、プレビューや実行のあとは結果の表になります。行をクリックすると、フルパスと判定の根拠（一致したキーワード、年月をどの文字から取ったか）が開きます。
- **下: 実行ボタン** — 画面の主要動作は「N 件のPDFを移動する」ひとつだけです。実行できないときはボタンが無効になり、その理由が左側に必ず表示されます。
- **共通設定** — 保存先やファイル安定確認などをまとめたダイアログです。変更できない設定（上書き禁止など）も理由付きで一覧表示します。
- **移動の取り消し** — 実行直後は「移動を取り消す」から、移動したファイルを元の場所へ戻せます。

## 仕分けの決まり

**保存先**

```
{共通保存先}\{保存先サブフォルダ}\{YYYY-MM}\ファイル名.pdf
```

**年月の判定** — ファイル名から次の表記を認識します。

```
2026.6 / 2026.06 / 2026-6 / 2026-06 / 2026_6 / 2026_06 / 202606
```

| 状況 | 保存先 | 結果コード |
| --- | --- | --- |
| 年月が1つ見つかった | `{保存先サブフォルダ}\YYYY-MM\` | `MOVED` / `COPIED_AND_DELETED` |
| 年月が見つからない | `{保存先サブフォルダ}\_年月不明\` | `MONTH_UNKNOWN` |
| 年月候補が複数ある | `{保存先サブフォルダ}\_年月確認要\` | `MONTH_AMBIGUOUS` |
| どのルールにも一致しない | `{ツールのフォルダ}\_unknown\` | `UNKNOWN` |
| 保存先に同名ファイルがある | `…\YYYY-MM\避難用_YYYYMMDD\` | `DUPLICATE_EVACUATED` |

**ルール判定** — 有効なルールを優先順位の昇順に評価し、最初に一致したものを使います。判定条件は次のすべてを満たすことです。

1. 拡張子が一致する
2. 「すべて含むキーワード」をすべて含む
3. 「いずれか含むキーワード」を1つ以上含む（指定がある場合）
4. 「含んではいけないキーワード」を1つも含まない

キーワードの大文字・小文字は区別しません。

## 事故防止の仕組み

- 既存ファイルは**絶対に上書きしません**（保存先を排他作成で確保してから書き込みます）
- 通常保存先では自動連番保存をしません。連番は避難用フォルダ内で同名だった場合のみ付けます
- 移動は「コピー → 存在とサイズの検証 → 元ファイル削除」の順に行います（`copy_verify_delete`）
- スキャン中・同期中のファイルを処理しないよう、更新からの経過秒数と、他アプリが使用中でないかを確認します
- `.sorter.lock` により二重起動を防ぎます
- `rules.json` はバックアップを作り、一時ファイル経由で置換します
- 保存先のパス長と Windows 禁止文字（`< > : " | ? *`）、予約語、上位フォルダへの脱出（`..`）を保存前に検査します
- すべての結果を CSV ログに残します

## 結果コード

| コード | 意味 |
| --- | --- |
| `MOVED` | 移動成功（`move` 方式） |
| `COPIED_AND_DELETED` | コピー・検証後に元を削除して移動成功 |
| `COPIED` | コピーのみ実行（`copy_only` 方式。元ファイルは残る） |
| `DUPLICATE_EVACUATED` | 同名ファイルがあり避難用フォルダへ保存 |
| `UNKNOWN` | ルール未一致 |
| `MONTH_UNKNOWN` | 年月不明 |
| `MONTH_AMBIGUOUS` | 年月候補が複数 |
| `SKIP` | 設定によりスキップ |
| `SKIP_FILE_NOT_STABLE` | ファイルが安定していないためスキップ |
| `UNDONE` | 移動を取り消して元の場所へ戻した |
| `ERROR_CREATE_FOLDER` | フォルダ作成失敗 |
| `ERROR_MOVE_FAILED` | 移動失敗 |
| `ERROR_COPY_FAILED` | コピー失敗 |
| `ERROR_DELETE_SOURCE_FAILED` | 元ファイル削除失敗 |
| `ERROR_VERIFY_FAILED` | 移動後検証失敗 |
| `ERROR_PATH_TOO_LONG` | パスが上限を超過 |
| `ERROR_RULE_INVALID` | ルール不正 |
| `ERROR_LOCKED` | 他プロセス実行中 |
| `ERROR_RULES_JSON_INVALID` | `rules.json` が不正 |
| `ERROR_FORBIDDEN_PATH` | 保存先パスが不正 |
| `ERROR_UNDO_FAILED` | 取り消しできなかった |
| `MATCH` | プレビュー専用。移動予定であることを示す |

## コマンドライン

```
py pdf_sorter_app.py server    ルール編集画面を起動
py pdf_sorter_app.py sort      rules.json に従いPDF移動を実行
py pdf_sorter_app.py preview   移動予定先をコンソール表示（移動しない）
```

## API（ローカル専用）

`127.0.0.1` のみで待ち受けます。Host / Origin ヘッダーを検査し、ローカル以外からの要求は拒否します。

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/` | ルール編集画面 |
| GET | `/api/rules`, `/api/status` | 現在の `rules.json` と画面用の付帯情報（`_meta`） |
| POST | `/api/rules` | 検証 → バックアップ → 一時ファイル経由で保存 |
| POST | `/api/preview` | 送信された設定で移動予定先を計算（移動しない） |
| POST | `/api/sort` | 設定を保存してから移動を実行 |
| POST | `/api/undo` | 直前の実行で移動したファイルを元へ戻す |

## 仕様書に対する補足

実装にあたって、仕様書に明記のない点を次のように決めました。

- **上書き禁止は常に有効**です。`forbid_overwrite` は事故防止の必須要件（仕様書 26）のため、設定値によらず `true` として扱い、画面では変更できない設定として理由付きで表示します。
- **対象は `.pdf` のみ**です。ルールに `.pdf` 以外の拡張子を指定した場合は保存時にエラーとして知らせます（将来の拡張余地として `extension` 項目は残しています）。
- **`duplicate_mode` に `skip`** を追加しました（同名時に移動しない）。既定は仕様どおり `evacuate` です。
- **移動の取り消し**を追加しました。基本設計 5「危ない操作は確認ダイアログではなく取り消しを用意する」に対応します。取り消せるのは元の場所にファイルが無く、移動先にファイルがある場合だけです（`copy_only` は対象外）。
- **`month_fallback: error`** の場合は移動せず、結果コード `MONTH_UNKNOWN` とメッセージで理由を記録します。
- **`rules.json` のバックアップ先**は `_rules_backup` フォルダとし、最新20件を保持します。
- **ポート 8765 が使用中**の場合は 8766〜8775 を順に試し、実際のURLをコンソールに表示します。
- **キーワードの一致は大文字・小文字を区別しません**（画面にも明記しています）。

## セキュリティ

- ローカルWebサーバーは `127.0.0.1` のみで待ち受けます
- 外部URLへの通信は行いません。画面のCSS/JavaScriptもツール自身が配信します
- ファイル名・保存先・ルール情報はローカルPC内だけで処理します
- 社内固有の情報はコードに含めず、すべて `rules.json` の設定値として扱います
